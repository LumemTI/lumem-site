# LUMEM — Soluções em TI

Site institucional estático em HTML, CSS e JavaScript.

## Testar localmente
Abra `index.html` no navegador ou execute um servidor estático (por exemplo, Live Server no VS Code).

## Publicar no GitHub Pages
1. Faça backup da versão atual do repositório.
2. Envie os arquivos desta pasta para a raiz do repositório, preservando a pasta `assets/`.
3. Em **Settings → Pages**, selecione a branch e a pasta raiz apropriadas.
4. Aguarde a publicação e teste os links, imagens e WhatsApp no celular e no computador.

## Antes de publicar
Confirme telefone, e-mail, área de atendimento e informações profissionais. O site usa links externos do Google Fonts e WhatsApp.
