# LUMEM — pacote responsivo para GitHub Pages

Esta versão mantém o visual desktop aprovado e refina os layouts de celular e tablet.

## Ajustes responsivos
- Serviços em uma coluna compacta no celular, sem alturas vazias exageradas.
- Grade de serviços em duas colunas no tablet, com o quinto cartão ocupando a largura completa.
- Melhor proporção de títulos, descrições, imagens e margens em telas menores.
- Seções “A LUMEM”, upgrade e contato ajustadas para telas pequenas.
- Botão flutuante do WhatsApp respeita as margens do dispositivo.
- Animações, cursores personalizados, imagens e domínio mantidos.

## Publicar no GitHub Pages
1. Extraia o ZIP.
2. Abra `LumemTI/lumem-site` no GitHub.
3. Clique em **Add file → Upload files**.
4. Envie o conteúdo de dentro da pasta `lumem-site-main` para a raiz do repositório (não envie a pasta externa como subpasta).
5. Faça o commit e aguarde o workflow do GitHub Pages concluir.
6. Abra `https://lumemti.com.br` e atualize a página. No computador, use `Ctrl + F5`; no iPhone, feche e reabra a página ou atualize-a.

## Não remova
Envie juntos `index.html`, `style.css`, `script.js`, `CNAME` e a pasta `assets`. O arquivo `CNAME` mantém o domínio `lumemti.com.br`.
