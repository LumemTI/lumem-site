# LUMEM | Soluções em TI

Site oficial da Lumem — manutenção de computadores e notebooks, hardware, sistemas e Segurança da Informação.

## Estrutura

- `index.html` — página principal
- `style.css` — estilos
- `script.js` — interações
- `assets/` — imagens, logo, favicon e demais recursos
