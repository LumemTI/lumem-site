# LUMEM Soluções em TI

Site institucional estático da LUMEM, preparado para GitHub Pages e domínio `lumemti.com.br`.

## Testar localmente
Abra `index.html` em um navegador. Para testar com servidor local, execute `python -m http.server 8000` nesta pasta e acesse `http://localhost:8000`.

## Publicação
Consulte `PUBLICAR-NO-GITHUB.md` antes de substituir os arquivos no repositório `LumemTI/lumem-site`. Preserve `CNAME` e a pasta `assets`.

## SEO
A página inclui canonical, metadados de compartilhamento, dados estruturados, `robots.txt` e `sitemap.xml`. Esses recursos ajudam o rastreamento e a compreensão do site, mas não garantem posição nos resultados de pesquisa.
