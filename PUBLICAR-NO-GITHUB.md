# LUMEM — pacote final para GitHub Pages

Este pacote contém o site completo, pronto para publicar a partir da raiz da branch `main` no repositório `LumemTI/lumem-site`.

## Publicação
1. Extraia o ZIP.
2. Abra o repositório `LumemTI/lumem-site` no GitHub.
3. Clique em **Add file → Upload files**.
4. Envie todo o conteúdo desta pasta, mantendo a estrutura e a pasta `assets`.
5. Confirme em **Commit changes** e aguarde o workflow do GitHub Pages terminar.

## Importante
- Envie `index.html`, `style.css`, `script.js`, `CNAME` e a pasta `assets` juntos.
- Não envie a pasta externa `LUMEM-final-git-v33` como uma subpasta dentro do repositório; envie os arquivos que estão dentro dela para a raiz.
- O arquivo `CNAME` contém `lumemti.com.br`.
- Para conferir o resultado, abra o site e use `Ctrl + F5`.
