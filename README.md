# LUMEM Soluções em TI — versão 18

Versão com a seção “Para empresas” redesenhada para comunicar melhor os benefícios do suporte de TI e incentivar o contato comercial.

## Testar localmente
Abra `index.html` em um navegador.

## Publicar no GitHub Pages
Envie o conteúdo desta pasta para a raiz da branch `main` do repositório `LumemTI/lumem-site`, mantendo a pasta `assets`, `index.html`, `style.css`, `script.js`, `favicon.ico` e `CNAME`.


Cursor personalizado incluído em `assets/cursor.cur`, ativado via `style.css` para dispositivos com mouse. Em telas touch, o cursor padrão é preservado.
