# LUMEM — site visual premium

Site estático preparado para GitHub Pages.

## Pré-visualizar
Abra `index.html` no navegador. Para testar o menu e os caminhos dos arquivos, também pode servir a pasta com qualquer servidor HTTP estático local.

## Serviços interativos
Os cinco cartões da seção de serviços abrem um painel com explicação, exemplos do atendimento e um botão para iniciar uma conversa no WhatsApp com a mensagem já preenchida para o serviço escolhido. O painel pode ser fechado pelo botão X, clicando fora dele ou usando Escape.

## Publicar no GitHub Pages
1. Extraia o ZIP.
2. Envie o conteúdo da pasta `LUMEM-site-visual-premium` para a raiz do repositório `LumemTI/lumem-site`.
3. Faça commit e aguarde a publicação do GitHub Pages.
4. O arquivo `CNAME` contém `lumemti.com.br`; confirme em Settings → Pages que o domínio personalizado está configurado e que o DNS está apontado corretamente.

## Imagens principais
- `assets/hero-servers-lumem.webp`: abertura com infraestrutura.
- `assets/upgrade-ssd-lumem.webp`: destaque de upgrade/manutenção.
- `assets/tecnico-rack-lumem.webp`: seção institucional.

## Antes de publicar
Confirme telefone, e-mail, domínio e links de contato. As fontes Manrope e Inter carregam do Google Fonts quando há conexão com a internet; se quiser servir tudo localmente, inclua os arquivos WOFF2 no projeto.
